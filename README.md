# LusHuaih-AI

**AI** | **GPT** | **LLM** | **智能助手** | **人工智能** | **AI Agent** | **ChatBot**

探索人工智能的无限可能，构建下一代智能对话体验。本项目是一个基于Flutter开发的AI聊天应用界面，展示了现代LLM技术在实际应用中的落地方案。

## 特性

- 精美的AI聊天界面
- 实时消息交互体验
- 跨平台支持（Android / iOS / Web）
- 自动构建与APK发布

## 技术栈

- Flutter
- Dart
- GitHub Actions CI/CD

## 开始使用

```bash
# 安装依赖
flutter pub get

# 运行应用
flutter run
```

## 构建APK

```bash
flutter build apk --debug
```
